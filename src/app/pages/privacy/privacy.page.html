Política de privacidade

Esta página explica, em linguagem simples, quais dados este site recebe, para que eles servem e quais são os seus direitos, de acordo com a Lei Geral de Proteção de Dados (LGPD, Lei nº 13.709/2018).

Quais dados o site recebe

  • Pelo formulário de contato: seu nome, a forma de contato que você escolheu (WhatsApp ou e-mail), o número ou e-mail, o melhor horário e, se você quiser, uma mensagem curta.
  • Pelo WhatsApp, e-mail ou Instagram: o que você enviar nesses aplicativos, que têm as próprias regras de privacidade.

Este site não usa cookies de rastreamento nem ferramentas de publicidade e não guarda informações no seu navegador.

Para que os dados são usados

Só para responder ao seu contato e combinar um possível atendimento. Os dados não são vendidos, não são usados para propaganda e não são compartilhados com outras pessoas, a não ser com o serviço técnico que recebe o formulário.

Dados de saúde e sigilo

Informações sobre saúde mental são dados sensíveis pela LGPD. Por isso, o formulário pede só o necessário para eu responder. Não escreva detalhes sobre sua saúde no formulário. Isso pode ser conversado com calma, em particular.

O que é dito nas sessões é protegido pelo sigilo profissional, previsto no Código de Ética Profissional do Psicólogo. Os registros do atendimento seguem as regras do Conselho Federal de Psicologia.

Por quanto tempo os dados ficam guardados

As mensagens de contato são guardadas só pelo tempo necessário para responder e combinar o atendimento. Se o atendimento não começar, elas são apagadas.

Seus direitos

Você pode pedir, a qualquer momento:

  • para saber quais dados seus estão guardados;
  • para corrigir dados errados;
  • para apagar seus dados;
  • para retirar o consentimento que você deu no formulário.
